# KRCE Green Campus — Environmental Protection Initiatives

> **Academic EVS Project (2026)**  
> **Institution:** K. Ramakrishnan College of Engineering (KRCE), Trichy, Tamil Nadu  
> **Course / Subject:** Environmental Studies (EVS)  
> **Project Theme:** Green Campus Initiatives for Environmental Protection

---

## 🌿 Project Overview

This web application represents a **premium, futuristic, highly interactive, and fully dynamic sustainability platform** built for an academic Environmental Studies (EVS) presentation at **K. Ramakrishnan College of Engineering (KRCE)**.

It envisions how modern engineering principles, renewable technologies, IoT telemetry, and circular ecology can transform a higher-education engineering campus into an environmentally responsible, regenerative community.

### 🛡️ Academic Authenticity Notice
In compliance with academic project standards:
- **No false or fabricated data:** All numerical data, metrics, and indicators are strictly classified as **"Proposed Targets"**, **"Project Goals"**, or **"Illustrative Data"**.
- This portal is an educational design proposal created to inspire students and faculty and does not represent an official institutional or governmental green audit.

---

## ⚡ Tech Stack & Architecture

- **Frontend Core:** React 19 + TypeScript + Vite 8
- **Styling & Design System:** Tailwind CSS v3 with custom forest/emerald/lime color palettes, glassmorphism, and responsive typography
- **Animations & Micro-interactions:** Framer Motion (spring physics, scroll reveals, stagger transitions)
- **3D Environmental Element:** Three.js (interactive 3D Earth Globe with coordinate markers, atmospheric shader glow, and graceful animated SVG/CSS fallback)
- **Icons:** Lucide React
- **Celebration Effects:** Canvas Confetti

---

## 🚀 Key Sections & Interactive Features

1. **Cinematic Hero:** Fullscreen environmental backdrop with translucent forest gradient, smooth typography reveal, and scroll indicator.
2. **Interactive 3D Earth Globe (Vision Section):** Stylized Three.js wireframe globe featuring orbital eco-rings, Trichy coordinate markers (`10.8° N, 78.7° E`), and mouse rotation.
3. **Core Initiatives (6 Action Pillars):**
   - Waste Management (*From waste to resource*)
   - Water Conservation (*Every drop matters*)
   - Clean Energy (*Powering tomorrow responsibly*)
   - Biodiversity (*Let nature thrive*)
   - Green Mobility (*Move smarter*)
   - Green Infrastructure (*Build with nature*)
   - *Clickable full-screen modal detailing challenges, solutions, benefits, and phased roadmaps.*
4. **Environmental Journey Roadmap:** 6-phase progressive timeline (*Understand, Reduce, Reuse, Restore, Measure, Inspire*) with animated connecting lines.
5. **Impact Dashboard:** In-viewport animated count-up counters and circular progress gauges displaying proposed targets:
   - 🌳 **500+** Tree Plantation Target
   - 💧 **50,000 L** Water Saving Target
   - ♻️ **2,000 kg** Waste Recycling Target
   - ☀️ **10,000 kWh** Clean Energy Target
   - 🚲 **300+** Green Commute Target
6. **Interactive Green Score Audit Tool ("How Green Is Your Campus?"):**
   - 10 interactive toggle parameters.
   - Dynamic tier classification (*Starting the Journey*, *Growing Greener*, *Green Progress*, *Green Campus Vision Leader*).
   - Confetti blast & educational disclosure.
7. **Closed-Loop Water System:** 5-stage hydrological flow (*RAIN ↓ COLLECT ↓ FILTER ↓ STORE ↓ REUSE*) with interactive leak detection and greywater cards.
8. **Clean Energy Micro-Grid:** Solar photovoltaic flow diagram with real-time IoT monitoring cards.
9. **Biodiversity & Indigenous Species:** Interactive botanical showcase featuring indigenous Tamil Nadu species (*Neem, Pongamia, Tulsi, Peepal*) and butterfly pollinator zones.
10. **Student Movement & Volunteer Registration:** Interactive student activity cards with a functional registration modal featuring department/year selections, animated pass generation, and confetti.
11. **Curated Visual Gallery:** Masonry gallery with category filters (*ALL, CAMPUS, NATURE, STUDENTS, ENERGY, WASTE, WATER*) and a full cinematic image Lightbox.
12. **KRCE Institutional Spotlight:** Dedicated college section detailing campus vision, regional context (Trichy, Tamil Nadu), and student leadership.
13. **Future Vision (Next-Gen Eco-Tech):** Futuristic concept cards including smart ultrasonic bin sensors, solar-powered net-zero labs, and student micro-fleets.
14. **Custom Desktop Cursor:** Central dot with trailing glowing ring, magnetic link hover, button expansion, and image "VIEW" tags (auto-disabled on mobile touch devices).

## 🛠️ How to Run Locally

### Prerequisites
- Node.js (v18+)
- npm (v9+)

### Installation & Execution
```bash
# Clone or navigate to the project directory
cd KRCE-Green-Campus

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

Development server runs at `http://localhost:5173/`.
